Conversion performed 2026-10-29:
- Source Tank2.fbx converted using Blender 4.3.2 to GLB.
- Canonical +Y up / -Z forward axes and metric-like scale.
- Separate Hull, TurretPivot/TurretMesh, BarrelPivot/BarrelMesh and Muzzle.
- Source alpha=0 material values corrected to opaque alpha=1; roughness .72, metallic .15.
- Four original track animation clips preserved: Backwards, Forward, TurningLeft, TurningRight.
- Original track skins retained; wheels remain merged into source Hull mesh.
- No code from third-party examples included.

Files redistributed with this project: tank_desert.glb, License.txt, this source note.
The converted source file tank_desert_ready.glb was renamed to tank_desert.glb without changing its bytes.
At runtime TankVisual applies a uniform .8136 scale and -.60m Y offset, separates the Forward clip into left/right tread animation channels, and adds an original ID plate / antenna. A separately authored procedural fallback is included under the project code license.
