# IRON RANGE · 3D Tank Battle

一个使用 **Godot 4** 制作的低多边形坦克驾驶与炮术训练场。灵感来自大型载具游戏的驾驶、独立炮塔与炮口弹道体验；这是原创单人原型，不是《战争雷霆》或《战地》的复刻，也不包含它们的代码或素材。

## 开始

1. 使用 **Godot 4.7.2** 打开 `project.godot`（其他 Godot 4 小版本尚未验证）。
2. 按 **F5** 运行，然后 **Enter** 开始驾驶。
3. 六辆静态训练坦克各有 **100 HP**。伤害取决于实际命中部位和入射角度；绕到侧面或后方通常更有效。摧毁全部六辆完成训练，也可自由探索环形道路、坡道与障碍区。

项目使用 Compatibility 渲染器，无插件、联网服务或额外下载。只需克隆源码，首次打开由 Godot 导入资源。

| 操作 | 按键 |
|---|---|
| 前进 / 倒车 | W / S（或 ↑ / ↓） |
| 左右履带转向 / 原地转向 | A / D（或 ← / →） |
| 瞄准炮塔 | 鼠标移动 |
| 开炮 | 鼠标左键 |
| 第一人称瞄准镜 / 外部视角 | **Shift 切换** |
| 放大视野 | 按住鼠标右键；瞄准镜内再放大一级 |
| 制动 | Space |
| 镜头对准车身方向 | C |
| 恢复车辆到起点 | F |
| 重置整座训练场 | R |
| 部件效果测试面板 | **F3** 开关；鼠标点击施加或清除玩家效果 |
| 暂停 / 释放鼠标 | Esc；Enter 恢复 |

### 视角与瞄准

- **Shift** 在外部跟随视角和第一人称瞄准镜之间切换。第一人称只隐藏玩家坦克的视觉网格；车体碰撞、炮塔运动和敌方坦克保持不变。
- 外部视角的**白色十字**是相机请求瞄准点，炮塔会限速追踪并补偿重力。
- 瞄准镜的**白色中心线**始终跟随真实炮管方向；鼠标直接操纵炮塔/炮管，不把镜头方向反复送回弹道补偿器，因此不会自己不断抬炮。需要利用落点环判断弹道下坠。
- **琥珀色圆环**始终来自当前真实炮口的弹道预测，包含重力、遮挡和镜头/炮口偏移；**绿色圆环**表示当前弹道将命中存活坦克，不保证穿透或高伤害。
- 瞄准镜位于炮尾附近、比炮轴高约 28 cm，不会把镜头移到墙外的炮口。炮管被近处障碍挡住时仍禁止开火。
- 右键在外部视角缩近；瞄准镜中从 32° 视场进一步放大至 16°。Shift 切回外部会重新显示己方坦克；R 重开会回到外部视角。
- 训练炮弹无限，装填时间 **3.2 秒**。目标上方显示 HP，命中反馈显示部位、扣血和入射角；坦克击毁后变成残骸。

### 简化装甲伤害

每辆目标坦克为 100 HP。弹丸逐段碰撞得到**真实世界命中点、表面法线、飞行方向及碰撞形状编号**。网格碰撞所属的车体、炮塔或履带决定部位；表面法线转到目标坦克自身坐标后判断前、侧、后、顶面（仅近水平表面判顶甲，倾斜首上装甲仍判前部），因此旋转目标不会改变判定规则。

入射角从表面法线计算：`cosθ = clamp(-飞行单位方向 · 表面单位法线, 0, 1)`；0° 为正入射，90° 为擦边。伤害使用抽象抗性而非真实装甲毫米数：

`damage = round(100 × 50 / (50 + resistance) × cosθ^1.5)`

**θ ≥ 75° 时跳弹，伤害为 0**。正入射时，车体正面约 31 HP、侧面约 49 HP、后部约 68 HP；炮塔正面约 26 HP，履带约 20 HP。具体抗性表在 `scripts/armor_damage.gd`。所有模型共用此游戏规则，不宣称对应真实车型装甲；没有穿深、内部乘员或弹药架模拟；下方部件失能采用独立的简化限时规则。

### 部件失能与测试面板

按 **F3** 打开可收起的小面板，可给**玩家坦克**施加引擎、左履带、右履带、炮管故障，或清除全部效果与装填。面板打开时释放鼠标、制动车辆并阻止误开火，**游戏和修复倒计时不暂停**；关闭后恢复驾驶与鼠标瞄准。Shift 瞄准镜中也能使用。Esc 才是真正暂停。

| 部件 | 有效命中与结果 |
|---|---|
| 后部引擎 | 实际车体碰撞、后向装甲法线，且命中车体后 35% 的中央引擎舱区域；**4 秒**不能驱动或原地转向，重力与地面接触仍有效 |
| 左 / 右履带 | 实际履带或负重轮碰撞按车体局部左右区分；对应驱动能力降至 **25%**，持续 **5 秒**，直线速度与转向减弱，单侧故障会产生偏转 |
| 炮管 | 独立炮管网格碰撞；正入射约 **8 HP**，**4 秒**不能开火，同时丢弃当前装填进度；修复结束后重新完整装填 **3.2 秒**，即使原来已装好也需重装 |

只有造成 HP 伤害且没有击毁坦克的命中才触发部件效果。跳弹、无效接触和残骸不触发；重复有效命中只**刷新**该部件时间，不无限叠加。多个不同部件可同时故障。玩家 HUD 和敌方血条旁显示剩余修复时间；炮管修复后的重新装填也有显示。暂停冻结计时，F 恢复玩家、R 重开和目标击毁会清除相应状态。

引擎舱是按实际最大车体网格包围盒构建的游戏区域：后 35%、中央 80% 宽、车体高度 20–95%，边界容差 2.5 cm，不声称对应真实车辆发动机布局。持续时间与履带倍率集中在 `scripts/component_status.gd`。

**靶车仍然静止，也不会自动射击。** 对它们的命中会真实更新共享的移动/开火许可与修复状态，并显示倒计时，但不能把静止靶车描述为“肉眼可见停车或停射”。使用 F3 玩家测试面板可以实际体验停驶、履带偏转、禁火和装填中断；没有因此增加战斗 AI。

## 已实现

- 加速、制动、倒车、高速转向衰减、停车双履带反转。
- CharacterBody3D 稳定底盘与四点地面采样：坡面行驶、车体俯仰/侧倾、碰撞与恢复。
- 真实 CC0 坦克模型，独立左右履带骨骼动画、炮塔、炮管与后坐。
- 限速炮塔、俯仰限制、重力弹道、逐段射线碰撞、炮口火光、烟尘、命中反馈。
- 跟随/环绕镜头、Shift 第一人称瞄准镜、右键放大、近景镜头防穿墙、暂停与失焦保护。
- 三款外形、六辆坦克目标、部位/角度伤害、限时部件失能、玩家效果面板、状态 HUD 和完整重置。
- 原创程序化沙漠训练场，以及原创合成引擎/炮声/撞击音效。

## 实现范围

这是偏易上手的驾驶训练原型，**不是专业坦克物理模拟器**：底盘采用稳定运动学控制，不计算独立负重轮刚体悬架、履带张力、真实装甲穿深或动力传动系统。四点地面采样驱动车体姿态；导入模型的车轮与车体网格合并，不能冒充逐轮独立悬架。目前没有 AI、联网、真实车辆型号数值或可破坏地形。

## 结构

- `scripts/tank_controller.gd` — 履带驱动、地面接触、独立瞄准与装填。
- `scripts/tank_visual.gd` — CC0 模型接入、左右履带分离动画、后坐。
- `scripts/tank_visual_procedural.gd` — 可选原创程序化坦克备用视觉。
- `scripts/main.gd` — 镜头、弹道预测、训练流程、反馈与音频。
- `scripts/shell.gd` — 真实炮弹逐段碰撞及世界空间命中数据。
- `scripts/armor_damage.gd` — 可独立测试的部位、入射角与 HP 伤害公式。
- `scripts/component_status.gd` / `component_panel.gd` — 共享故障/修复计时与可收起玩家测试面板。
- `scripts/range_world.gd` / `range_target.gd` / `range_hud.gd` — 场地、目标与 UI。
- `tests/range_test.gd` — 真实场景与物理帧的自动化回归。
