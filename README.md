# 雷霆战争

GodotParty API 4 / 默认协议普通局，支持 1–8 人在线游玩。由正式大厅的小游戏池选择本包；入口 `party_round.tscn`，使用统一准备页、菜单和结算页。

- 单人：驾驶 M1 Abrams，限时击毁六个固定靶标；可用 F 将车辆回正至出生点。
- 2–8 人：同场自由交战，每人一条生命，最后存活者获胜。超时先按存活、生命排序；已淘汰者按存活时长，再比较伤害。完全相同则并列。不开启 AI 或本地分屏。
- 房主设置回合时限，默认 300 秒。所有人的模拟从准备确认后开始。断线者退出排名；房主离开由框架结束会话。
- 房主模拟移动、炮塔转动、弹道、装甲与部件受损，客户端只发送逻辑输入；20 Hz 状态快照在客户端平滑显示。观战房主仍执行模拟。

W/S 前后、A/D 转向、空格刹车、鼠标瞄准、左键开炮、Q 切换穿甲弹 / 高爆弹、Shift 切换第三人称 / 炮手瞄准镜、滚轮缩放当前视角、C 镜头回正。操作可在本机设置中改键。Esc 打开框架菜单，联机模拟和计时继续。多人不允许手动恢复生命、重置车辆或重置全场。

战斗界面仅保留左下速度 / 血条、右下主炮 / 炮弹剪影和装填进度。中心十字与大圈代表玩家瞄准方向，小圈代表当前炮管弹道落点；命中、部件瘫痪和击杀在准星旁短暂提示。瞄准镜刻度随倍率缩放。

穿甲弹弹速更快、正面伤害更高，装填 3.2 秒；高爆弹装填 4 秒，具有受掩体阻挡、随距离衰减的 4 米爆炸范围，可损坏履带，也会伤及自身。单个目标不会同时受到同一炮弹的直击与溅射伤害。切弹重新装填，已发射的炮弹保留原弹种。这些参数用于游戏平衡。

所有玩家使用 `assets/m1_abrams/m1_abrams.glb`，来自用户的 M1_Abrams.blend。炮塔、炮管、履带与车轮独立运动；车体碰撞与部件命中使用贴合游戏比例的简化形状。训练目标保留 Quaternius 模型与原装甲角度判定，参见 CREDITS.md。

运行时只依赖包内导出模型，不需要本机安装 Blender 或访问原始素材目录。API、清单和正常回合可用性应在完整 GodotParty 工程中验证；本地自动检查不代替真实网络和人工操控验收。
