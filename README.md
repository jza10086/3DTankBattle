# IRON RANGE · 3D Tank Battle

一个使用 **Godot 4** 制作的低多边形坦克驾驶与炮术训练场。灵感来自大型载具游戏的驾驶、独立炮塔与炮口弹道体验；这是原创单人原型，不是《战争雷霆》或《战地》的复刻，也不包含它们的代码或素材。

## 开始

1. 使用 **Godot 4.7.2** 打开 `project.godot`（其他 Godot 4 小版本尚未验证）。
2. 按 **F5** 运行，然后 **Enter** 开始驾驶。
3. 每个靶子需要 **2 次命中**。摧毁全部 **6 个目标** 完成训练；也可自由探索环形道路、坡道与障碍区。

项目使用 Compatibility 渲染器，无插件、联网服务或额外下载。只需克隆源码，首次打开由 Godot 导入资源。

| 操作 | 按键 |
|---|---|
| 前进 / 倒车 | W / S（或 ↑ / ↓） |
| 左右履带转向 / 原地转向 | A / D（或 ← / →） |
| 瞄准炮塔 | 鼠标移动 |
| 开炮 | 鼠标左键 |
| 炮手放大视野 | 按住鼠标右键 |
| 制动 | Space |
| 镜头对准车身方向 | C |
| 恢复车辆到起点 | F |
| 重置整座训练场 | R |
| 暂停 / 释放鼠标 | Esc；Enter 恢复 |

### 瞄准提示

- **白色十字**：相机请求瞄准的方向。
- **琥珀色圆环**：当前炮口实际弹道的落点；会随炮塔追踪、炮管俯仰限制和地形遮挡变化。
- **绿色圆环**：当前弹道将击中目标。
- 炮塔有转速限制，快速甩鼠标后要等炮塔转到位。炮管被近处障碍挡住时禁止开火。
- 训练炮弹无限，装填时间 **3.2 秒**。击中目标一次会改变靶板颜色，第二次将其击倒。

## 已实现

- 加速、制动、倒车、高速转向衰减、停车双履带反转。
- CharacterBody3D 稳定底盘与四点地面采样：坡面行驶、车体俯仰/侧倾、碰撞与恢复。
- 真实 CC0 坦克模型，独立左右履带骨骼动画、炮塔、炮管与后坐。
- 限速炮塔、俯仰限制、重力弹道、逐段射线碰撞、炮口火光、烟尘、命中反馈。
- 跟随/环绕镜头、炮手放大、近景镜头防穿墙、暂停与失焦保护。
- 六靶训练目标、耗时/命中率结算、可重复重置，极简全画幅 HUD。
- 原创程序化沙漠训练场，以及原创合成引擎/炮声/撞击音效。

## 实现范围

这是偏易上手的驾驶训练原型，**不是专业坦克物理模拟器**：底盘采用稳定运动学控制，不计算独立负重轮刚体悬架、履带张力、装甲穿深或动力传动系统。四点地面采样驱动车体姿态；导入模型的车轮与车体网格合并，不能冒充逐轮独立悬架。目前没有 AI、联网、真实车辆型号数值或可破坏地形。

## 结构

- `scripts/tank_controller.gd` — 履带驱动、地面接触、独立瞄准与装填。
- `scripts/tank_visual.gd` — CC0 模型接入、左右履带分离动画、后坐。
- `scripts/tank_visual_procedural.gd` — 可选原创程序化坦克备用视觉。
- `scripts/main.gd` — 镜头、弹道预测、训练流程、反馈与音频。
- `scripts/shell.gd` — 真实炮弹逐段碰撞。
- `scripts/range_world.gd` / `range_target.gd` / `range_hud.gd` — 场地、目标与 UI。
- `tests/range_test.gd` — 真实场景与物理帧的自动化回归。
