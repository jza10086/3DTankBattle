# 雷霆战争

GodotParty API 4 / 默认协议普通局，支持 1–8 人在线游玩。由正式大厅的小游戏池选择本包；入口 `party_round.tscn`，使用统一准备页、菜单和结算页。

- 单人：驾驶所选载具，限时击毁六个固定靶标；可用 F 将车辆回正至出生点。
- 2–8 人：同场自由交战，每人一条生命，最后存活者获胜。超时先按存活、生命排序；已淘汰者按存活时长，再比较伤害。完全相同则并列。不开启 AI 或本地分屏。
- 房主设置回合时限，默认 300 秒。准备确认后每人选择载具，所有仍在线的玩家确认选车后开始模拟。断线者退出排名；房主离开由框架结束会话。
- 房主模拟移动、炮塔转动、弹道、装甲与部件受损，客户端发送 20 Hz 不可靠有序的持续逻辑输入，开火/复位边沿单独可靠；20 Hz 最少载具姿态在本地平滑显示，生命、弹药及修理/装填截止时间按变化可靠通知。炮弹由 MultiplayerSpawner 管理生成/销毁，普通弹道本地推进，导弹用 MultiplayerSynchronizer 以 0.05 秒间隔同步必要位置/速度。观战房主仍执行模拟。

W/S 前后、A/D 转向、空格刹车、鼠标瞄准、左键开炮、按住右键同轴机枪连射、Q 切换武器 / 弹药、Shift 切换第三人称 / 炮手瞄准镜、滚轮缩放当前视角、C 镜头回正。操作可在本机设置中改键。Esc 打开框架菜单，联机模拟和计时继续。多人不允许手动恢复生命、重置车辆或重置全场。

战斗界面仅保留左下速度 / 血条、右下主炮 / 炮弹剪影和装填进度。中心鼠标牵引大圈代表玩家瞄准意图，各激活炮管在渲染帧实时按物理插值后的真实炮管指向投射平滑清晰的副准星（双联机炮显示双炮管方向准星，含装甲穿透变色、受阻提示与装填进度环），开火同轴机枪时附带机枪指向准星；炮长瞄准镜十字与下坠密位刻度随真实炮管轴线和倍率动态联动。命中、部件瘫痪和击杀在准星旁短暂提示。

弹药由可配置的 `TankShellSpec` 资源（`ammo/*.tres`）与对应炮弹模型（`ammo/models/*.tscn`）定义，支持按弹种独立配置名称、模型、尺寸/口径、弹速、重力、装填、穿深与距离衰减、转正角、跳弹区间、口径碾压、超压穿深、直击伤害与溅射半径/伤害；各载具在 `vehicles/*.tres` 中绑定主武器弹种、同轴机枪弹种及装甲倍率（`armor_scale`）。穿甲弹随距离衰减穿深并受转正与跳弹角影响；高爆弹触发超压（命中薄弱顶盖/车尾/轻装甲）与受掩体阻挡的范围溅射；反坦克导弹为化学能恒定穿深并带视线制导与爆炸溅射。单个目标不会同时受到同一炮弹的直击与溅射伤害。同一炮管内切弹（如 M1 的 AP / HE）会重新装填，已发射的炮弹保留原弹种；不同装备槽位（如 BMPT / 布拉德利的机炮与导弹发射架，由 `TankShellSpec.reload_slot` 区分）各自独立装填并在后台并行计时，切换装备不会退弹或中断装填。

可选载具：

| 载具 | 武器 | 游戏定位 |
| --- | --- | --- |
| M1 Abrams | 105 mm 穿甲弹 / 高爆弹 | 坚固装甲、单发炮击 |
| BMPT 终结者 | 双联 30 mm 机炮 / Ataka 导弹 | 交替连射、持续压制 |
| M2A2 布拉德利 | 25 mm 机炮 / TOW 导弹 | 机动较快、装甲较薄 |

新载具按住左键连续机炮射击；切换至导弹后左键发射，持续瞄准引导飞行，导弹飞行最长 8 秒。Ataka / TOW 装填分别为 7.5 / 8.5 秒。机炮与导弹发射架独立并行装填，切换不会退弹，右下武器栏同步显示后台未选中装备的剩余装填秒数；当前弹种和武器剪影随载具更新。确认选车后本局不能更换，单人打靶与多人对战均可使用三种载具。

三个玩家模型分别来自用户的 M1_Abrams.blend、BMPT_Terminator.blend、M2A2_Bradley.blend，导出存放于 `assets/m1_abrams/`、`assets/bmpt/`、`assets/bradley/`。炮塔、炮管、履带与车轮独立运动；车体碰撞与部件命中使用贴合游戏比例的简化形状。训练目标保留 Quaternius 模型与原装甲角度判定，参见 CREDITS.md。

车辆的可编辑独立预制体场景位于 `vehicles/*.tscn`，挂接固定车体、`TankArmorZone` 分部位毫米装甲碰撞区（可在检查器中逐块微调正面/侧面/背面/顶盖/底甲毫米数及碰撞体形态）、炮塔/多炮口数组（`primary_muzzles` / `missile_muzzles`）、车轮、履带路径及预制体级 `hp_override` / `weapon_overrides` 覆盖；`vehicles/*.tres` 为 `TankVehicleSpec` 资源，统一配置载具名称、描述、剪影/武器图标、最大血量、全局装甲倍率、机动参数（极速/倒速/加减速/转向/炮塔转速/俯仰角范围）及绑定弹种资源。运行时根据选车实例化场景，只推进履带相位，不重新生成固定模型或碰撞。三种训练靶保存在 `scenes/targets/`，每块碰撞明确指定装甲区域、可损伤部件和对应网格，残骸姿态更新也使用该引用。

入口 `scripts/main.gd` 协调部署、逻辑输入与房主模拟；`tank_camera.gd` 管理本机视角、缩放和弹道预览，`audio/combat_audio.tscn` 管理战斗空间音效、车内警报与反馈 Cue；每辆车的 `audio/vehicle_audio.tscn` 分别控制发动机、履带和炮塔转动循环，音量由协议作用域设置控制。选择与装填等动态文案使用包内中文翻译及命名占位符。统一准备／结算页面仍沿用协议现有契约，整树禁用的迁移等待共享 G01 一起完成。

运行时只依赖包内场景与资产，不需要本机安装 Blender 或访问原始素材目录。API、清单和正常回合可用性应在完整 GodotParty 工程中验证；本地自动检查不代替真实网络和人工操控验收。

同轴机枪为三车独立副武器，按载具配置 `coax_ammo`、`mg_belt_size` 与 `mg_reload_seconds`，主武器装填时仍可使用（M1 / 布拉德利为 7.62 mm 100 发弹链、10 发／秒、4 秒装填；BMPT 按真实设计采用中置夹于双联 2A42 之间的 7.62 mm PKTM 同轴机枪，配备绿色曳光弹、250 发弹链箱、750 发／分钟理论射速、8 秒车内远程换箱装填）。右下角机枪剪影同时显示弹量和装填进度；改键与主武器分开。机枪对正面车体／炮塔不造成伤害，对暴露履带或车体后部造成少量伤害，不会一发就触发部件瘫痪。弹道、射速、弹量和伤害均由房主判定；输入过期、菜单阻挡、死亡或退出后停止连射。

声音沿用空白模板的 PartyGameAudio 作用域与 PartyAudioCue，受协议的本机音量、静音、暂停和退出清理控制。32 个空间瞬态声源保留叠音，优先保留重炮和爆炸尾音；每辆车各有发动机、履带、炮塔循环，导弹飞行声随弹体释放。只有自己的车辆播放装填、受击、部件瘫痪／低血量警报和维修完成提示；命中、瘫痪、击杀确认只反馈给射手。观战者仍能听见场景空间音效，不接收车内警报。音效资源可在 `audio/cues/` 调整，来源、修改与商用许可见 `doc/GP_tank_war_assets_audio_sources.md`。声音是游戏化混音，不宣称真实载具录音。

开战前选择 M1 Abrams、BMPT 或 M2A2 布拉德利。1 人打靶；2–8 人坦克淘汰赛。机炮可按住左键连射，导弹随瞄准方向制导；Q 切换武器。每人一条生命，最后存活者获胜。Esc 打开菜单，比赛继续。 按住右键使用同轴机枪，100 发弹链打空后自动装填。
